Reflexiones sobre Chia Amisola y la Poética Digital

1. La Web como Espacio Afectivo

Chia Amisola propone entender la web no como una mera herramienta utilitaria o comercial, sino como un espacio íntimo, poético y de preservación afectiva. Frente a la estandarización de las redes sociales hegemónicas, el sitio web personal es un gesto de resistencia donde el código (HTML/CSS) actúa como materia viva.

2. La Corporalidad del Código y el Hipervínculo

Construir un sitio en HTML implica habitar la red con intención. El enlace o hipervínculo se transforma en una huella de memoria, un puente poético entre archivos, textos y subjetividades que resiste a la obsolescencia digital.
