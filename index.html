Reflexiones sobre Chia Amisola y la Poética Digital

El sitio web personal como espacio afectivo y archivo vivo

1. El Sitio Web como Espacio Afectivo

La práctica artística e interdisciplinary de Chia Amisola nos invita a replantear la forma en que habitamos la red. Frente a la homogeneización de las plataformas hegemónicas y las redes sociales comerciales —que reducen la experiencia digital a algoritmos de consumo y formatos rígidos—, el sitio web personal se erige como un territorio de resistencia, intimidad y preservación afectiva.

A través del código hecho a mano y el diseño web enfocado como proceso creativo, la web deja de ser una mera herramienta utilitaria para convertirse en un espacio habitado, donde la memoria y la subjetividad encuentran un refugio tangible.

2. El Código y la Poética del Hipervínculo

Escribir HTML y CSS de manera artesanal implica una relación corporal y poética con el entorno digital. Cada etiqueta, clase y enlace es un gesto deliberado de diseño y pensamiento.

El hipervínculo no funciona únicamente como una ruta técnica de navegación, sino como un conector afectivo y poético. El enlace nos permite tejer trayectorias de memoria, conectando archivos personales, notas y fragmentos dentro de un ecosistema en constante transformación.

3. Memoria y Archivo Vivo

La obra de Chia Amisola nos impulsa a entender el archivo no como un depósito estático de datos del pasado, sino como una práctica viva. La fragilidad del entorno digital y la caducidad de las plataformas hacen que mantener una presencia independiente en HTML adquiera una dimensión ética de cuidado y permanencia.
